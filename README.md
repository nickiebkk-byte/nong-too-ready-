# น้องตู้รู้ทัน

แอปจดของในตู้เย็น เตือนของใกล้หมด และแนะนำเมนูจากของที่มี

## เอาขึ้น GitHub Pages
1. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, support.js, manifest.webmanifest, โฟลเดอร์ assets และ icons) โดยคงโครงสร้างโฟลเดอร์เดิม
2. ไปที่ Settings > Pages > Source เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
3. รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## เพิ่มเป็นแอปบน iPhone
เปิดลิงก์ใน Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม

## หมายเหตุ
- ต้องมี support.js และโฟลเดอร์ assets อยู่ข้างๆ index.html เสมอ
- บนจอคอมจะแสดงในกรอบโทรศัพท์พร้อมแถบเลือกสีพื้นหลัง บนมือถือจะเต็มจอ
- ฟอนต์ Prompt โหลดจาก Google Fonts เมื่อมีอินเทอร์เน็ต
- ข้อมูลในเวอร์ชันนี้เป็นข้อมูลตัวอย่าง ยังไม่บันทึกถาวรเมื่อรีเฟรชหน้า
